# Janelle Loyola - Personal Bio Link & Portfolio Site

This ZIP package contains the complete website code customized for **Janelle Loyola**, featuring her photo as the main profile picture.

## Files Included
- `index.html`: Main HTML file containing the content structure.
- `style.css`: Modern glassmorphism UI styling, gradients, and animations.
- `profile.jpg`: The profile photo provided in the prompt.

## How to Test Locally
1. Extract/Unzip `Janelle_Loyola_Portfolio.zip`.
2. Double-click `index.html` to view the website in your browser.

## How to Deploy to Netlify
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the extracted folder onto the page.
3. Your customized site will be deployed and live in seconds!
